How it works

The money is agreed before the work starts, and released when it passes.

AI handles the parts that make freelance work slow: writing the brief, pricing it, checking the result and paying out. People do the actual work.

1

Describe

The client sends a message or a voice note. No brief template.

2

Scope & price

The Scoping agent writes acceptance criteria and a price. The client approves the budget once, through PayPal.

3

Do the work

The freelancer gets the brief and only the context the job needs, in the app or in their own editor.

4

Verify

The Review agent checks each criterion and shows its reasoning, so both sides see why.

5

Get paid

On a pass, the payment agent releases the approved amount through PayPal. Invoice and receipt are generated automatically.

Built on PayPal

PayPal's agent tools do the paying.

Engine's agents connect to PayPal through the official PayPal Agent Toolkit and MCP server, so every money step is a real PayPal operation the client and freelancer can see in their own accounts.

Orders · authorize

Orders · capture

Released on a pass

A passing review triggers the capture. The agent can only capture what the client already authorized.

Invoicing

Invoices write themselves

Approved items become a PayPal invoice with the criteria and review attached. No one types one up.

Refunds

Clean refunds

If work is cancelled or fails and isn't fixed, the authorization is voided or refunded, not argued about.

Disputes

Disputes with evidence

The criteria, each verdict and its reasoning become the evidence trail if a dispute is ever opened.

Transactions

Guardrails

The AI pays, but only what the client already agreed to.

Letting an agent move money only works if it can't move the wrong amount to the wrong person. These limits are built into the tools themselves.

Never more than authorizedThe payment agent can capture up to the amount the client approved for that job, and nothing else.
No amount, no destinationPayment tools never take an amount or a recipient as input. Both come from the approved job.
The reviewer can't payThe agent that judges the work has no payment tools. Judging and paying are separate.
A human can always step inEither side can appeal a verdict to a person before the payment releases. Design and copy work waits for the client's approval.
